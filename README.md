**Niño 3.4 Experimental Anomaly Forecast **

This is an experimental machine-learning project developed for educational and research purposes. It explores historical sea-surface temperature anomalies in the Niño 3.4 region of the central-eastern equatorial Pacific Ocean, an area commonly monitored when studying El Niño and La Niña.
The project uses monthly ocean temperature anomaly data obtained from the National Oceanic and Atmospheric Administration (NOAA), covering 1950 to the latest available observation in the dataset.
A temperature anomaly represents the difference between the observed sea-surface temperature and a reference average. Positive values indicate warmer-than-average conditions, while negative values indicate cooler-than-average conditions.


The purpose of this project is to explore how machine learning can be applied to historical climate data and make the results accessible for learning and awareness.
The forecasts are experimental estimates. They are not official El Niño or La Niña predictions, and they should not be used alone to make climate-related decisions. Official ENSO assessments require additional oceanic and atmospheric indicators, sustained observations, and expert analysis.
